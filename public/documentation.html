📋 Dokumentasi Reset Database Satgas/OSIS

Panduan lengkap untuk mereset database tahun ajaran baru

⚠️

PERINGATAN PENTING!

Menjalankan skrip ini akan MENGHAPUS SEMUA data anggota dan SEMUA riwayat absensi sebelumnya secara PERMANEN. Pastikan Anda sudah melakukan backup data jika diperlukan!

📝 Langkah-Langkah Penggunaan

1

Login ke Neon Tech

  • Kunjungi neon.tech
  • Login menggunakan akun Google Anda
  • Buat database baru dengan nama sesuai tahun, contoh: satgas-2027 atau osis-2027
2

Buka SQL Editor

  • Setelah berhasil masuk ke dashboard Neon
  • Cari dan klik menu "SQL Editor"
  • Pastikan Anda sudah memilih database yang benar
3

Sesuaikan Data Anggota

Sebelum menjalankan skrip, ubah data anggota sesuai kebutuhan Anda. Perhatikan struktur data berikut:

('OSIS-2027-01', 'Nama Lengkap', 'Devisi', 'Jabatan'),
('OSIS-2027-02', 'Nama Lengkap', 'Devisi', 'Jabatan');

💡 Tips: Untuk data terakhir, tutup dengan tanda titik koma ;

4

Jalankan Skrip

  • Salin seluruh skrip SQL yang sudah disesuaikan
  • Tempelkan di SQL Editor
  • Klik tombol "Run" atau "Execute"
  • Tunggu hingga proses selesai

🗂️ Struktur Database

📊 satgas_members

Tabel untuk menyimpan data anggota Satgas/OSIS

Kolom Keterangan
nipd ID unik anggota (contoh: OSIS-2027-01)
full_name Nama lengkap anggota
devisi Divisi anggota (Inti, Keamanan, Acara, dll)
jabatan Jabatan anggota (Ketua, Koordinator, Anggota)
is_active Status aktif anggota (otomatis true)

📅 attendance_records

Tabel untuk menyimpan riwayat absensi

Kolom Keterangan
member_id Referensi ke NIPD anggota
attendance_time Waktu absensi (otomatis)
status Status kehadiran (Hadir, Izin, Sakit, dll)

⚙️ settings

Tabel untuk pengaturan sistem absensi

💻 Contoh Kode Lengkap 

DROP TABLE IF EXISTS attendance_records;
DROP TABLE IF EXISTS satgas_members;
DROP TABLE IF EXISTS settings;

CREATE TABLE satgas_members (
    id SERIAL PRIMARY KEY,
    nipd VARCHAR(50) UNIQUE NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    devisi VARCHAR(50),
    jabatan VARCHAR(50),
    is_active BOOLEAN NOT NULL DEFAULT true
);

CREATE TABLE attendance_records (
    id SERIAL PRIMARY KEY,
    member_id VARCHAR(50) NOT NULL REFERENCES satgas_members(nipd),
    attendance_time TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    attendance_date DATE NOT NULL DEFAULT CURRENT_DATE,
    status VARCHAR(50) NOT NULL DEFAULT 'Hadir',
    reason TEXT,
    UNIQUE(member_id, attendance_date)
);

CREATE TABLE settings (
    id INT PRIMARY KEY,
    is_active BOOLEAN NOT NULL DEFAULT false,
    is_keamanan_form_active BOOLEAN NOT NULL DEFAULT false,
    is_izin_form_active BOOLEAN NOT NULL DEFAULT false
);

💡 Tips & Catatan Penting

  • • Pastikan format NIPD konsisten: OSIS-TAHUN-NOMOR
  • • Backup data lama sebelum menjalankan skrip reset
  • • Ubah tahun pada NIPD sesuai tahun ajaran baru (contoh: 2027, 2028)
  • • Divisi yang umum: Inti, Keamanan, Acara, Dokumentasi, Humas, Konsumsi
  • • Jabatan yang umum: Ketua, Wakil Ketua, Sekretaris, Bendahara, Koordinator, Anggota
